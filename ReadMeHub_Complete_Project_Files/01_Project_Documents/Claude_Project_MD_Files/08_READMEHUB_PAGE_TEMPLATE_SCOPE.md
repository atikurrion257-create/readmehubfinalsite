# READMEHUB PAGE AND TEMPLATE SCOPE

## Purpose
Plan the templates extending the approved homepage. This is a scope checklist, not proof that any template already exists.

## Required templates
1. AI Tools / Software Directory
2. Single Tool Review
3. Blog Archive
4. Single Blog Article
5. Category Archive
6. Comparisons Archive
7. Single Comparison
8. Deals and Coupons Archive
9. Single Deal or Coupon
10. Search Results
11. About ReadMeHub
12. Editorial Methodology
13. Affiliate Disclosure
14. Contact and Report an Error
15. Privacy Policy
16. Terms of Service
17. Custom 404

The approved homepage remains unchanged unless explicitly authorized.

## Shared components
Reuse existing components where available: header/navigation, mobile navigation, footer, search, breadcrumbs, page introduction, section headings, category navigation, tool/article/comparison/deal cards, editorial metadata, verification badges, CTA buttons, newsletter panel, pagination, filters, comparison table, form fields, empty states, related content, and affiliate disclosure notice.

Do not duplicate a component with slightly different styling without a functional reason.

## Template notes
- Directory: searchable/filterable tool cards and useful empty states.
- Tool review: overview, features, limitations, pricing source, use cases, alternatives, related content, methodology.
- Blog archive: featured article, categories, article cards, pagination.
- Single article: readable content width, metadata, optional table of contents, sources, related content.
- Category archive: relevant introduction and category-specific content.
- Comparisons archive: comparison cards and filters.
- Single comparison: criteria, readable table, source information, use cases, alternatives, mobile table strategy.
- Deals archive: verification status, terms, expiry, filters, active/expired/unverified states.
- Single deal: terms, code only when real, destination, verification metadata, disclosure.
- Search results: content types, filters, loading and no-results states.
- About: mission and actual supplied information only.
- Methodology: transparent research, verification, update, and correction policies.
- Affiliate disclosure: plain-language commercial relationship explanation.
- Contact/report error: accessible forms and success/error states.
- Privacy/terms: readable legal-document templates; actual policy content needs owner/legal confirmation.
- 404: helpful search, homepage action, relevant category links.

## Trust and data integrity
Never invent ratings, reviews, testimonials, product prices, discounts, coupon codes, expiry dates, author credentials, company history, user counts, or testing claims. Optional data should disappear gracefully. Unverified offers must not look verified; expired offers must not appear active.

## Implementation handoff
For every template, map WordPress object/query, Elementor structure, dynamic title/content/image, taxonomy, ACF fields, related content, conditional visibility, empty state, plugin/edition dependencies, and responsive behavior.
